Universal integration adapter

One framework for every bank format: map once, approve, run

  • Reads a bank's own format specification or a sample file and discovers its fields
  • A small language model proposes a mapping to the ERP's data dictionary
  • A person approves every row; approved mappings are saved and versioned
  • A deterministic engine generates the payment file or imports the statement, with no AI in the live path
  • Tried on NACHA/ACH, SEPA pain.001 and MT940, across delimited, fixed-width and XML files

Built to replace 10–19 person-days of manual analysis, mapping and coding per bank format.
